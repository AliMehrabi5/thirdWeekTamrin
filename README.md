# User Management Dashboard

A simple User Management Dashboard built with HTML, CSS and JavaScript.

## Features

- Fetch users from API
- Display users as cards
- Search users by name
- Loading state
- Error state
- Empty state
- Retry button
- Responsive design

## API

This project uses JSONPlaceholder:

https://jsonplaceholder.typicode.com/users

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await
- REST API
- JSON
